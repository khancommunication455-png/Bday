# 🎂 Alina ❤ Aneeza — Happy Birthday Website

A cinematic, interactive birthday experience made with love — for **Aneeza**, from her bestie **Alina**.

## ✨ What's Inside

The journey flows through 11 magical scenes:

1. **Cinematic Intro** — a starry opening dedicated to the birthday girl
2. **Hero** — "Happy Birthday Aneeza" with floating balloons, confetti & a 3D starfield
3. **Chat** — a playful iMessage-style conversation
4. **The Origin** — "It all started with a simple Hello…"
5. **Beautiful Wishes** — six gorgeous wish cards, each one unwraps into a full-screen message with confetti
6. **A Letter From Alina** — a heartfelt letter that types itself out
7. **Friendship Games** — catch the hearts, then prove you're the Bestie Queen 👑
8. **The Forever Question** — "Will you be my best friend Forever?"
9. **Movie Credits** — starring Aneeza, the Birthday Star
10. **100 Reasons I Appreciate You**
11. **Outro** — a sweet goodbye with "Songs That Remind Me of You"

## 🚀 Run Locally

**Prerequisites:** Node.js

```bash
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.

## 🎵 Assets

Put these files in the `public/` folder (already included):

- `music.mp3` — background music
- `notification.mp3` — the surprise notification chime

## 💛 Personalize

All the names, wishes, reasons, quiz questions, and chat messages live in
`src/constants.ts` — edit them freely to make it your own.

Enjoy the celebration! 🎉
